## 1. Что мы строим

Публичный Marketplace + Creator Dashboard.

Два пользовательских пути:
```text
Visitor:  Discover → Inspect → Download .slr   (без регистрации)
Creator:  Login → Create Archive → Upload → Configure → Publish → Analytics
```

Frontend **не** отвечает за: payment verification, entitlement, device license, `.slr` crypto,
Solana-транзакции, приватные ключи, подсчёт метрик. Всё это — backend/viewer.
Оплата происходит внутри Viewer, не в браузере.

Ключевые продуктовые константы (менять нельзя):
```text
USDC only · platform fee 5% · creator 95% · price immutable after create
max_devices = 1 · network fees paid by SolArch · non-custodial payout wallet
public metrics = views / downloads / paid_unlocks
supported content = PDF, PNG, JPG/JPEG, WebP, DOCX, XLSX
```

### Стек

```text
React + TypeScript + Vite      SPA, без Next.js — SEO проекту не нужен
TanStack Query                 кеш, staleTime, инвалидация, retry
TanStack Router                типобезопасные роуты и search params (?sort=)
Tailwind CSS
shadcn/ui на Base UI           Base UI — дефолт shadcn с релиза 2026-07
MSW                            мок backend на уровне сети; те же хендлеры в тестах
zod                            схемы DTO = контракт + рантайм-проверка ответов
Структура                      apps/web как npm workspace (INTEGRATION.md §2)
```

Одобрены к использованию, но ещё не подключены (ставим по месту применения):
`react-hook-form` + `zod` резолвер — на S7 (форма создания архива);
`zustand` — только если появится клиентское состояние, которое не покрывает TanStack Query.

Проверено по актуальной документации: `npx shadcn@latest init -t vite` даёт шаблон Vite;
CLI v4 поддерживает флаг `--base` для выбора примитивов, Base UI идёт по умолчанию.
Точные команды фиксируем на S0 после реального запуска CLI.

## 4. Контракты, от которых зависим

Эндпоинты, которые использует фронт (из `docs/API.md`):

```text
POST /v1/auth/wallet/challenge
POST /v1/auth/wallet/verify
GET  /v1/me
POST /v1/auth/logout

POST  /v1/archives
GET   /v1/archives/:archiveId
PATCH /v1/archives/:archiveId
POST  /v1/archives/:archiveId/publish
POST  /v1/archives/:archiveId/unpublish
GET   /v1/archives/:archiveId/download
GET   /v1/archives/:archiveId/analytics?period=7d|30d|all

POST /v1/uploads/init
PUT  <upload transport>
POST /v1/uploads/:uploadId/complete
POST /v1/uploads/:uploadId/cancel

GET /v1/marketplace/archives?sort=&search=&category=&page=
GET /v1/marketplace/archives/:slug
GET /v1/marketplace/archives/:slug/files
GET /v1/marketplace/archives/:slug/download
```

Общие статусы (нельзя выдумывать свои строки):
```text
technical:   draft | uploading | processing | ready | failed
marketplace: draft | published | unpublished | blocked
```

Деньги: decimal string (`"10.00"`), не float. Превью 95/5 можно считать до create,
после create показываем `economics` из ответа backend.

Публичный file listing — только эти поля:
```text
display_path · display_name · extension · mime_type · size_bytes
```

Проверено на S11a: `tsc -b`, `oxlint` (ноль предупреждений), `vitest` (271/271),
`vite build`.
Демо-кошелька в production-сборке по-прежнему нет.

Живьём пройдена аналитика: переход с манифеста на странице архива → воронка за всё
время → сужение окна до 7 и 30 дней (числа и обе конверсии меняются вместе с окном,

архив не существует. Обе локали, светлая и тёмная тема, 1280px и 390px.
Горизонтальной прокрутки нет — проверено обходом дерева, а не глазом.

Фавиконка Vite заменена на знак SolArch — тот же, что слева от надписи в шапке.

(`seal-mark.tsx` и `public/favicon.svg`) — менять надо в обоих сразу,
иначе вкладка и шапка разойдутся.

В консоли на публичных страницах остаётся одна строка: `401` на `GET /v1/me`.
Это не ошибка приложения, а ответ мока гостю; чем ответит настоящий backend — Q12.

Организационный вопрос (открыт): по `INTEGRATION.md` §12 первым шагом идёт

| F23 | Мусор в параметрах гасится в умолчание, а не бросает исключение | 2026-09-07 | Адрес каталога публичный: его правят руками и обрезают при пересылке. `?sort=что-нибудь` обязан дать каталог, а не белый экран. Каждое поле схемы завёрнуто в `.catch(undefined)` |
| F24 | Значения по умолчанию в адресе не хранятся | 2026-09-07 | `/` вместо `/?sort=popular_week&q=&page=1`. Все ссылки каталога собираются одной функцией `catalogLinkSearch` |
| F25 | Сортировки — ссылки, а не выпадающий список | 2026-09-07 | У каждого порядка выдачи свой адрес; работает средняя кнопка мыши и открытие в новой вкладке. Пять коротких подписей в меру ширины помещаются |
| F26 | `aria-current` на чипе сортировки ставим сами | 2026-09-07 | Роутер считает ссылку активной по точному совпадению адреса; на второй странице совпадения нет, а подсветка нужна. Значение то же (`page`), поэтому расхождения не возникает |
| F27 | Ввод в поиск не сбрасывает прокрутку (`resetScroll: false`) | 2026-09-07 | Поиск пишет в адрес каждые 300 мс, и при `scrollRestoration` каждая запись утаскивала страницу к шапке. Найдено на живой странице, не тестом |
| F28 | `keepPreviousData` в каталоге | 2026-09-07 | Смена сортировки или страницы не схлопывает список в скелет: прошлая выдача остаётся и приглушается. Тесты обязаны ждать новую выдачу, а не первую попавшуюся |
| F29 | 4xx не повторяются | 2026-09-07 | 404 на снятый с публикации архив повтором не исправить — он только задерживал показ страницы. Повторяем сбои сети и 5xx |
| F30 | `PER_PAGE` в моке уменьшен до 6, фикстур стало девять | 2026-09-07 | На пяти архивах и странице в 12 постраничность не появлялась вовсе и осталась бы непроверенной |
| F31 | Опись файлов группируется по `display_path`, порядок backend не меняется | 2026-09-07 | Структуру несёт только путь — отдельного поля папки в контракте нет. Сортировать по алфавиту значило бы переставлять содержание книги: порядок файлов задаёт автор |
| F32 | `extension` и `mime_type` в описи не рисуем | 2026-09-07 | Имя файла уже кончается расширением. Повторить его в каждой из сорока строк — шум, а не сведения; поля остаются в контракте и в типах |
| F33 | Условия лицензии — прозаический перевод `license_policy`, а не вывод полей | 2026-09-07 | Гость платит уже после скачивания, поэтому «что даёт оплата» обязан прочесть до него. Выключенный водяной знак строки не даёт вовсе: говорить «его нет» не о чем |
| F34 | Обложка живёт в жёстком кадре 1200×630 с `object-cover` | 2026-09-07 | Пропорции обложек контракт не оговаривает (Q3). Без фиксированного кадра каждая обложка двигала бы весь текст под собой при загрузке. Битая ссылка убирает блок целиком |
| F35 | Прелоад страницы архива — `prefetchQuery` в loader, а не `ensureQueryData` | 2026-09-07 | `ensureQueryData` бросил бы 404 снятого архива в обработчик ошибок роутера, и вместо «архив недоступен» человек увидел бы аварийный экран. `prefetchQuery` не бросает и не блокирует переход |

### Сессия 13 — 2026-09-10 · меню доведено (S11a, продолжение)

Три правки заказчика по живому экрану: бургер вместо слова, плавное появление
и вопрос — не сделать ли меню слоем поверх страницы.

Ответ на вопрос оказался связан со второй правкой. Панель стояла в потоке и
отодвигала страницу вниз (F123); «плавно» для неё означало бы плавно перекладывать
всё содержимое — самое дорогое, что делает браузер, и самое заметное глазу.
Слой всплывает над неподвижной страницей и стоит два свойства (F125). Запирать
экран при этом не стали: `modal="trap-focus"` держит табуляцию внутри списка,
но оставляет живой шапку, иначе бургер — то место, куда рука тянется закрыть
меню, — оказался бы под затемнением и не отвечал (F126). Затемнение поэтому
начинается под шапкой.

Escape, нажатие мимо, возврат фокуса на кнопку и снятие слоя после анимации
достались от Base UI: своего кода в меню осталось ровно столько, сколько нужно,
чтобы закрыть его на переходе. Свои слушатель Escape и возврат фокуса удалены.

Найдено в браузере, а не тестом:

- **Сдвиг и поворот не анимировались.** Tailwind v4 пишет `translate` и `rotate`
  в отдельные свойства, а не в общий `transform`, поэтому `transition-[…,transform]`
  их не подхватывает: панель проявлялась, но прыгала на место, а крест складывался
  рывком. Видно только покадрово — в замерах `translate` менялся между кадрами
  скачком с `-8px` сразу на `none`. Лечится списком свойств:
  `transition-[opacity,translate]` у панели и `transition-[top,rotate,scale,opacity]`
  у черт бургера. После правки обе величины идут плавно: 0 → 26° → 40° → 45°.
- **Открытие мышью ставило первую ссылку в кольцо фокуса** — «Каталог» читался
  выбранной строкой. `initialFocus` теперь двигает фокус только при открытии
  с клавиатуры: пальцем и мышью список открывают, чтобы прочитать, а не чтобы
  попасть в первый пункт.

Бургер стоит последним у правой кромки (F128). Отрицательный отступ, равняющий
значок по кромке страницы, переехал с переключателя темы на бургер и возвращается
обратно с `lg` — поправка всегда у последнего в ряду; проверено измерением:
и значок бургера на 390px, и значок темы на 1280px совпадают по правому краю
с карточками каталога. Область нажатия расширена до 36×44 невидимой псевдострокой:
28×28 — размер соседних переключателей, но для большого пальца этого мало.

Высота строки шапки вынесена в токен `--header-height`: меню рисуется в портале
и висит ровно под шапкой, а достать её высоту оттуда через DOM нельзя.

Проверки: `tsc -b`, `oxlint` (ноль предупреждений), `vitest` 271/271, `vite build`.
Новый тест держит то, что перестало быть видимым: кнопка без надписи обязана
сообщать `aria-expanded`. Остальные тесты меню не переписывались — имена
не изменились, и это сам по себе хороший знак: менялась форма, а не поведение.

Живьём: 390px и 1280px, обе локали, светлая и тёмная тема, гость и вошедший автор.
Проверено покадрово, что слой доживает анимацию закрытия и только потом исчезает.
Горизонтальной прокрутки нет. В консоли та же одна строка `401` на `GET /v1/me` (Q12).

Место под ссылку готово в `ProductNav`, содержание упирается в Q6.
